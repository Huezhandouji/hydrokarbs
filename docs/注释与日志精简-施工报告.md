## 3. 迁移信息(仅存于注释、设计文档 00-16 与修正案未覆盖的独有信息;新家 = 本节)

### 装配与桥接

- `HydrokarbsAssembly`:fallback-mode 默认值的装配级接线——默认资源出厂空模式 id 依赖 `discover` 的 SPI 半边注册兜底,代码级读默认维持空串,「单一默认源 = 默认资源」;`HydrokarbsApiImpl` 为薄委托,主线程回程口 = `Threads::runOnMain`,`fallbackModeId` 惰性读充当摘除回退编排的配置源。
- `HydrokarbsApiImpl`:出厂空模式经 SPI 注册、**不入 `modeClaims`**——第三方 `unregisterMode` 对它命中越权分支 = 出厂回退模式天然防摘(31 号修正案只裁缺省去向管线退场,未明载此推论);离线测试经构造器注入直通/单线程假主线程执行器。
- `SessionRecipe`:组件 id 由供给面类型名推导,与引擎装配路径(`deriveComponentId`)同源。
- `MatchModeInstanceEventPort`:占位接口,因 `MatchModeInstancePort#events()` 签名引用先行落位,待后续文档接管。
- `SessionEventBus`:mirror 接线拓扑——生产端 = `HydrokarbsAssembly` 装配步 ⑨ 的 `SessionEventBus#publish`,数据源为服务订阅面与 `HydrokarbsApi#subscribeSessionEvents`;订阅归属「发起组件」用调用栈反查实现(与实例容器 later 登记同法)。
- `MatchModeInstanceView`:component/ 三件私有适配器的 `session()` 已由暂返 null 改为经服务集只读口真接通。
- `MatchModeInstance`:构造失败零玩家痕迹是阶段 2 切换回退判据的结构前提(§3.2-B)。
